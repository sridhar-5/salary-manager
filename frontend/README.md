# Frontend

The React client for Salary Manager. Setup, the live app, and the demo login are in the [project README](../README.md#frontend).

From this directory, with `frontend/.env` setting `VITE_API_BASE_URL`:

```bash
npm install
npm run dev
```

The app runs at [http://localhost:5173](http://localhost:5173).

```bash
npm test
npm run lint
npm run build
```
